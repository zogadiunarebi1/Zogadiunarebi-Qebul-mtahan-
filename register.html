§1. Riyazi hesablamalar - Natural ədədlər

1. Tək və Cüt ədədlər +
Natural ədədlər

Natural ədədlər — saymaq üçün istifadə olunan ədədlərə deyilir. Natural ədədlər çoxluğu N hərfi ilə işarə olunur. Çoxluq 1-dən başlayır və sonsuzdur.

N = {1, 2, 3, 4, 5, ...}

Natural ədədlər tək (Məs: 1, 3, 5, ...) və cüt (Məs: 2, 4, 6, ...) olur.

Tək və cüt ədədlər

Sonu 0, 2, 4, 6 və 8 rəqəmlərindən biri ilə bitən natural ədədlərə cüt ədədlər deyilir. Məs: 20, 32, 344, 356 və 728.

Sonu 1, 3, 5, 7 və 9 rəqəmlərindən biri ilə bitən natural ədədlərə tək ədədlər deyilir. Məs: 21, 53, 125, 987 və 889.

Tək və cüt ədədlərin xassələri:
Burada T — tək ədəd, C — cüt ədəddir.

T + T = C    T + C = T    C + C = C
T × T = T    T × C = C    C × C = C
Tn = T    Cn = C
2. Əks ədədlər +

Yalnız işarəsinə görə fərqlənən ədədlərə əks ədədlər deyilir. Bu ədədlərə uyğun nöqtələr koordinat başlanğıcına nəzərən simmetrik yerləşir.

Məsələn: 5-in əksi -5-dir, -5-in əksi isə 5 (və ya +5)-dir.

-2-nin əksi 2-dir, 2-nin əksi isə -2-dir.

Hər bir ədədin yalnız bir əksi var. 0-ın əksi özüdür. a ədədinin əksi -a olar. -(-7) yazılışı "-7-nin əksi" kimi oxunur və 7-yə bərabərdir: -(-7) = 7.
Ümumiyyətlə, -(-a) = a olur.
3. Qarşılıqlı əks ədədlər +

Cəmi sıfra bərabər olan ədədlərə qarşılıqlı əks ədədlər deyilir.

Məsələn: -5 və 5 qarşılıqlı əks ədədlərdir, çünki -5 + 5 = 0.

Yəni bir-birinin əksi olan ədədlərin cəmi həmişə 0-dır.

a + (-a) = 0
