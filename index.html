Tam ədədlər və onların müqayisəsi

Qaydanı öyrən, nümunələrə bax və testləri həll et.

1. Tam ədədlər nədir?

Tam ədədlərə mənfi tam ədədlər, sıfır və müsbət tam ədədlər daxildir.

Mənfi tam ədədlər: −1, −2, −3, −4, ...

Sıfır: 0

Müsbət tam ədədlər: 1, 2, 3, 4, ...

Qeyd: 2,5 və −1,7 tam ədəd deyil.

2. Ədədlərin müqayisəsi

Ədəd oxunda sağda yerləşən ədəd daha böyükdür.

−2 > −5

Çünki −2, ədəd oxunda −5-in sağında yerləşir.

3 > 0 > −4

Müsbət ədəd sıfırdan, sıfır isə mənfi ədəddən böyükdür.

−3 > −8

İki mənfi ədəddən sıfıra daha yaxın olanı böyükdür.

3. Yadda saxla

  • Müsbət tam ədədlər sıfırdan böyükdür.
  • Mənfi tam ədədlər sıfırdan kiçikdir.
  • Sıfır nə müsbət, nə də mənfi ədəddir.
  • −3 > −8, çünki −3 sıfıra daha yaxındır.

4. Özünü yoxla

Hər sualda bir cavab seç. Seçimdən sonra izah görünəcək.

Cavablandırılan: 0/10
